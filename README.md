Project Overview

This project demonstrates how security threats can be detected automatically by collecting and correlating logs generated during simulated cyber attacks in a controlled enterprise environment. The system monitors activities from multiple machines, detects suspicious behavior such as brute-force attacks, and visualizes alerts through a centralized monitoring dashboard.

## Objectives
- Simulate enterprise-style cyber attacks
- Collect logs from different systems
- Correlate logs for threat detection
- Generate alerts for suspicious activities
- Visualize attack data using dashboards

## Technologies Used
-Docker
-Elasticsearch
-Kibana 
-Kali Linux
-Ubuntu Linux

## Features
-Centralized log collection
-Real-time monitoring
-Brute-force attack detection
-Alert generation
-Security dashboard visualization
-Simulated enterprise attack environment

## Detection Workflow
-Attack is launched from attacker machine
-Victim system generates logs
-Kibana agent collects logs
-Logs are indexed and correlated
-Alerts appear in dashboard

## Expected Output
-Detection alerts in Kibana dashboard
-Authentication failure logs
-Brute-force attack visualization
-Security event monitoring
